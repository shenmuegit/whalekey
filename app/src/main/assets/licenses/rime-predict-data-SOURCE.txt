With official OpenCC==1.2.0 installed, compile the pinned data/dictionary/
TSCharacters.txt and TSPhrases.txt with opencc_dict -f text -t ocd2; place
both .ocd2 files beside the pinned data/config/t2s.json. Then run:
python tools/prepare_predict.py app/src/main/assets/licenses/rime-predict-data-predict.txt app/src/main/assets/licenses/rime-predict-data-predict-simplified.txt PATH/TO/t2s.json
Focused check: set OPENCC_T2S_CONFIG to that t2s.json, then run
python tools/test_prepare_predict.py
Native compilation: sh tools/build_predict_android.sh PATH/TO/SOURCE-DIRECTORY
Extract pinned librime-predict, librime and darts-clone sources into that directory:
- librime-predict: 920bd41ebf6f9bf6855d14fbe80212e54e749791
- librime: de4700e9f6b75b109910613df907965e3cbe0567 (1.16.1)
- darts-clone: 87b71afd6cf784953e3c08f24c64203397f3b724
The script uses the repository's prebuilt librime and parent Android SDK NDK
28.0.13004108. Run its build_predict-android executable on x86_64 Android:
build_predict-android predict.db < rime-predict-data-predict-simplified.txt
