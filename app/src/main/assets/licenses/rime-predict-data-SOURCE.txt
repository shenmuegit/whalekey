Underlying data sources:
- Rime essay: https://github.com/rime/rime-essay
- Rime octagram data: https://github.com/lotem/rime-octagram-data
Both declare GNU LGPL version 3. The LGPL text is included as
rime-predict-data-LGPL-3.0.txt, and its incorporated GNU GPL version 3
is included as rime-ice-GPL-3.0.txt. Essay author/source acknowledgements
are preserved in rime-predict-data-essay-AUTHORS.txt.
The official data release does not identify the exact essay/octagram input
revisions. Their contemporaneous LGPL declarations can be inspected at:
https://github.com/rime/rime-essay/tree/e0519d0579722a0871efb68189272cba61a7350b
https://github.com/lotem/rime-octagram-data/tree/31d9b2e081af7708939d2eeb516f2b4c80b6a23f
These are license references, not assertions about the release's training inputs.

The release is Traditional-Chinese oriented. WhaleKey preserves its bytes;
contexts absent from this data produce no native next-word candidates.
